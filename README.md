# Pacman AI Projects

A collection of artificial intelligence assignments based on the classic UC Berkeley Pacman projects, implemented in Python. This repository includes solutions and supporting project materials for core AI topics such as search, adversarial reasoning, and reinforcement learning.

## Overview

This project collection covers several key areas of AI:

- Search algorithms and heuristic planning
- Multi-agent decision-making
- Reinforcement learning and value iteration
- Problem-solving in the Pacman environment

The repository is organized by project and includes PDFs and implementation folders for each assignment.

## Included Projects

### Project 0

Introductory setup and fundamentals for the Pacman environment. This is typically the starting point for configuring the workspace and preparing the project files.

### Project 1: Search

Focuses on classical search techniques such as:

- depth-first search
- breadth-first search
- uniform-cost search
- A* search
- heuristic design and problem modeling

This project teaches how agents reason about state spaces and choose efficient paths.

### Project 2: Multi-Agent Search

Builds on the search project with adversarial and multi-agent planning, including concepts such as:

- minimax
- alpha-beta pruning
- evaluation functions
- decision-making under uncertainty and opposing agents

### Project 3: Reinforcement Learning

Covers machine learning through interaction and rewards, including techniques such as:

- value iteration
- Q-learning
- policy evaluation
- learning from environment rewards rather than explicit supervision

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/alyalsayed/Pacman_Projects.git
cd Pacman_Projects
```

2. Open the relevant project folder for the assignment you want to work on.

3. Follow the project instructions provided in the corresponding PDF or README files.

4. Run the Python scripts in the project folder as required by the assignment.

## Requirements

This project is primarily Python-based and typically requires:

- Python 3.x
- standard Python libraries
- the Pacman project environment or starter code provided with the assignment
